Direitos Autorais

O Zero Game respeita os direitos autorais dos artistas, compositores, produtores, gravadoras, fotógrafos e demais criadores de conteúdo.

Conteúdos publicados no Zero Game

O Zero Game procura disponibilizar apenas conteúdos próprios ou conteúdos para os quais exista autorização adequada para publicação.

As músicas disponibilizadas para reprodução ou download devem pertencer ao responsável pela publicação ou estar devidamente autorizadas para utilização.

Conteúdos de terceiros

O Zero Game não pretende reivindicar a propriedade de músicas, imagens, vídeos, nomes artísticos, logotipos ou outros materiais que pertençam a terceiros.

Quando um conteúdo pertence a outra pessoa ou entidade, os respectivos direitos continuam pertencendo aos seus legítimos titulares.

Resultados do YouTube

O Zero Game pode apresentar resultados de pesquisa provenientes do YouTube para facilitar a descoberta de músicas, artistas e vídeos.

Esses resultados direcionam o utilizador para o YouTube. O Zero Game não hospeda nem disponibiliza para download os vídeos encontrados através dessa pesquisa.

Os conteúdos encontrados no YouTube permanecem sujeitos às regras e aos direitos dos respectivos titulares e da plataforma onde estão hospedados.

Pedido relacionado com direitos autorais

Se você for o titular dos direitos de determinado conteúdo publicado no Zero Game e acreditar que esse conteúdo foi disponibilizado sem a devida autorização, entre em contacto connosco.

Para facilitar a análise do pedido, recomendamos informar:

  • Nome do titular dos direitos;
  • Nome da música ou conteúdo;
  • Link da página onde o conteúdo aparece;
  • Explicação sobre os direitos que possui sobre o conteúdo;
  • Informações de contacto para podermos responder ao pedido.

Análise de solicitações

Os pedidos recebidos serão analisados com base nas informações fornecidas. Quando for necessário, o Zero Game poderá solicitar informações adicionais para verificar a situação do conteúdo.

Caso seja identificada uma publicação que não deveria estar disponível, serão avaliadas as medidas adequadas para resolver a situação.

Responsabilidade dos utilizadores

Os utilizadores e colaboradores responsáveis pelo envio de conteúdos devem garantir que possuem os direitos ou as autorizações necessárias para publicar esse material.

Não é permitido utilizar o Zero Game para distribuir deliberadamente conteúdos protegidos por direitos autorais sem autorização.
